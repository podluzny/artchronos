# SPEC-KB-001: Справочники базы знаний

| Поле | Значение |
|---|---|
| Блок | BL-13 |
| Requirements | FR-KB-001, FR-KB-002, FR-KB-003, FR-KB-004, FR-KB-005, FR-KB-008, FR-KB-009 |
| Scenarios | SC-KB-001, SC-KB-003 |
| Business rules | BR-047, BR-048, BR-049, BR-051, BR-035 |
| Domain entities | KnowledgeEntry, KnowledgeLink, ContentReference, MediaAsset |
| Permissions | `knowledge.read`, `knowledge.manage` |
| ADR | ADR-010 |
| Статус | Implemented |

## Purpose
Вести объекты истории искусства как связанные записи, чтобы выбирать их в формах, ссылаться на них из текста и видеть, где они используются (BRD 10.2, 10.9, A.1).

## Actors
Teacher, Admin (ведение); Student, Expert (чтение и выбор).

## Preconditions
Пользователь активен и имеет `knowledge.read`; для изменений — `knowledge.manage`.

## Input
| Поле | Тип | Обязательно | Валидация |
|---|---|---|---|
| kind | enum | да | PERSON, ARTWORK, COLLECTION, MOVEMENT, PERIOD, TECHNIQUE, TERM; после создания не меняется |
| name | string | да | 1–300 символов, без `[`, `]`, `<`, `>` |
| slug | string | нет | Пусто — генерируется из названия. Буквы (латиница и кириллица), цифры, `-`, `_`; 1–80 символов; начинается и заканчивается буквой или цифрой; уникален в пределах вида |
| altNames | string[] | нет | Варианты написания, через запятую или с новой строки |
| description | text | нет | До 5000 символов; якоря разрешены (SPEC-KB-002) |
| yearFrom, yearTo | int | нет | −5000…2100, yearFrom ≤ yearTo |
| attrs | по виду | нет | PERSON: birthText, deathText, country. ARTWORK: workKind, dateText, dimensions, inventoryNo, location. COLLECTION: city, country, url, creditLineTemplate. TERM: forms[] |
| связи | id[] | нет | Допустимые пары: ARTWORK → AUTHOR(PERSON), COLLECTION(COLLECTION, одна), TECHNIQUE, MOVEMENT, PERIOD; PERSON → MOVEMENT; MOVEMENT → PARENT(MOVEMENT), PERIOD; PERIOD → PARENT(PERIOD); TERM → SEE_ALSO(TERM) |

## Business rules
* BR-047 — используемый объект не удаляется, только архивируется.
* BR-048 — slug уникален в виде и не меняется при наличии ссылок.
* BR-049 — архивный объект нельзя выбрать в новых связях и якорях.
* BR-051 — медиа, связанное с произведением, получает атрибутивные поля из него.
* BR-035 — все изменения журналируются.

## Main scenario
1. Teacher открывает «Материалы → Авторы» и создает запись: название, варианты написания, годы, описание. Slug генерируется.
2. Создает произведение: выбирает авторов, собрание, технику, направление; указывает датировку.
3. В медиатеке выбирает для изображения поле «Произведение». Атрибутивные поля медиа заполняются из произведения.
4. На карточке объекта «Где используется» показывает медиа, вопросы, тесты, задания и другие объекты, которые на него ссылаются.

## Alternative scenarios
* A1 Slug занят → ошибка поля `slug`.
* A2 Связь с объектом другого вида или с архивным объектом → ошибка поля связи.
* A3 Удаление используемого объекта → отказ с предложением архивировать.
* A4 Изменение slug используемого объекта → отказ.
* A5 Связь объекта с самим собой или цикл PARENT → ошибка.

## Data changes
KnowledgeEntry, KnowledgeLink, MediaAsset.artworkId, AuditLog (`knowledge.created|updated|archived|restored|deleted`).

## Authorization
`knowledge.read` ANY — список, карточка, «где используется»; `knowledge.manage` ANY — создание, изменение, архив, удаление. Отказ — 403 без изменений.

## UI behavior (AdminJS)
Группа навигации «Материалы»: Медиатека, Авторы, Произведения, Собрания и музеи, Направления и стили, Периоды, Техники и материалы, Термины. Поиск по названию, вариантам и slug. Действие «Где используется». Подсказки к полям — `src/adminjs/hints.ts`.

## Acceptance criteria
| ID | Критерий | Тип |
|---|---|---|
| AC-KB-001.1 | Teacher создает запись каждого вида; пустой slug генерируется из названия; аудит `knowledge.created` | positive |
| AC-KB-001.2 | Повторный slug в том же виде и недопустимый slug отклоняются; в разных видах одинаковый slug допустим | negative |
| AC-KB-001.3 | Student и Expert читают справочники, но не создают и не изменяют записи (прямой вызов — FORBIDDEN) | permission |
| AC-KB-001.4 | Связь с объектом недопустимого вида, с архивным объектом или с самим собой отклоняется | negative |
| AC-KB-001.5 | Удаление объекта, на который ссылаются контент или связи, отклоняется; неиспользуемый объект удаляется | negative |
| AC-KB-001.6 | Изменение slug используемого объекта отклоняется; название меняется свободно | negative |
| AC-KB-001.7 | Архивирование и восстановление журналируются; архивный объект не выбирается в новых связях | positive |
| AC-KB-001.8 | Поиск находит объект по названию, варианту написания и slug; «Где используется» перечисляет источники ссылок | positive |
| AC-KB-001.9 | Медиа, связанное с произведением, получает автора, название, датировку, технику, собрание и инв. № из произведения | positive |
