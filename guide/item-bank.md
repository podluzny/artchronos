# Банк вопросов

## Типы вопросов

Тип определяет, как студент отвечает и как начисляются баллы. Ведет администратор; остальные роли видят список.

| Тип | Способ ответа |
|---|---|
| Один из нескольких | выбор одного варианта |
| Несколько из нескольких | выбор нескольких вариантов |
| Верно / неверно | выбор из двух |
| Выбор изображения | варианты — изображения |
| Атрибуция произведения | изображение-стимул и выбор автора/названия |
| Сопоставление | пары «левый — правый столбец» |
| Хронологический порядок | расставить элементы по порядку |
| Краткий ответ | ввод слова или фразы |
| Развернутый ответ | текст, оценивается вручную |

| Поле | Описание |
|---|---|
| Код | Латиница и цифры: `attribution_detail`; после создания не меняется. |
| Название, Описание | Как тип называется в редакторе вопросов. |
| Interaction | Способ ответа (выбор, сопоставление, порядок, ввод текста). |
| Конфигурация | Параметры в пределах способа ответа (число вариантов, перемешивание и т. п.). |
| Оценивание | Метод начисления баллов: точное совпадение, частичный балл, по парам, по позициям, ручная проверка. |
| Версия, История версий | Изменение конфигурации создает новую версию типа; существующие вопросы остаются на своей. |
| Вопросов, В активных заданиях | Где тип используется. |

**Действия:** «Изменить конфигурацию», «Активировать», «Деактивировать». Неактивный тип нельзя выбрать для нового вопроса.

## Вопросы

Вопрос — единица банка. Студент создает вопросы в рамках активного задания; преподаватель — также для банка курса без задания. Содержимое хранится по версиям.

### Поля вопроса (редактор)

| Поле | Обязательно | Описание |
|---|---|---|
| Задание / Курс | да | Где создается вопрос. Студент — только в назначенном активном задании. |
| Тип вопроса | да | Только типы, разрешенные заданием. После создания не меняется. |
| Формулировка | да | Текст вопроса; допускается простое форматирование. Ссылки на базу знаний: `@slug`. |
| Варианты ответа | по типу | Текст и/или изображение, отметка верного; каждый вариант имеет постоянный ключ. |
| Медиа (стимул) | нет | Изображение или видео к вопросу. Нужны alt text и подтвержденные права. |
| Темы | для отправки | Хотя бы одна тема курса (в задании — из тем задания). |
| Учебные цели | нет | Какую цель проверяет вопрос. |
| Сложность | нет | 1–5; используется в фильтрах и правилах отбора. |
| Баллы | нет | Баллы по умолчанию при добавлении в тест. |
| Теги | нет | Ключевые слова для поиска. |
| Пояснение | нет | Что студент увидит после ответа. |

### Поля в списке и карточке

Формулировка, Тип, Состояние версии, Версия, Автор, Задание, Курс, Темы, Сложность, Баллы, Проверка (замечания готовности), Версии, Хэш содержимого, Статус.

### Действия

| Действие | Описание |
|---|---|
| Создать вопрос | Открывает редактор |
| Редактировать черновик | Только версия-черновик |
| Предпросмотр / Быстрый просмотр | Как увидит студент (варианты перемешаны) |
| Отправить на экспертизу | Для вопросов банка курса; вопросы заданий отправляются в составе теста |
| Отозвать отправку | Пока экспертиза не начата |
| Новая версия | Из возвращенной, утвержденной или архивной версии |
| Удалить черновик | Ни разу не отправлявшийся черновик удаляется, иначе — в архив |
| Сравнить версии | Различия по полям между двумя версиями |
