# Задания

**Задание** — поручение студентам подготовить вопросы и тесты по темам курса. Создает и ведет преподаватель курса (или администратор).

## Поля задания

| Поле | Обязательно | Описание |
|---|---|---|
| Курс | да | Курс, по материалам которого готовятся тесты. |
| Название | да | Видно студентам. До 200 символов. |
| Инструкции | нет | Что нужно сделать: тема, объем, требования. Можно ссылаться на объекты базы знаний (`@slug`). |
| Вопросов, мин. / макс. | да | Сколько вопросов должно быть в тесте студента (от 1 до 100); проверяется при отправке. |
| Тестов на студента | да | Сколько тестов один студент может создать по заданию (от 1 до 10). |
| Дедлайн | для активации | Срок первой отправки теста. Доработки после экспертизы разрешены до закрытия задания. |
| Мой срок | — | Для студента: дедлайн с учетом личного продления. |
| Статус | — | Черновик, Активно, Закрыто, В архиве. |
| Автор, Эксперт по умолчанию | — | Кто создал задание и кто автоматически назначается экспертом тестов. |
| Тем, Типов вопросов, Адресатов | — | Сводка настройки (вычисляется). |

## Настройка (действие «Настроить»)

| Поле | Описание |
|---|---|
| Темы | Вопросы студентов должны относиться к выбранным темам или их подтемам. |
| Учебные цели | Необязательно: на какие цели ориентированы вопросы. |
| Типы вопросов | Только эти типы студенты смогут создавать в задании. |
| Группы | Задание получат все студенты выбранных групп. |
| Студенты | Дополнительно — отдельные студенты вне групп. |
| Эксперт по умолчанию | Назначается на тесты студентов автоматически. |

## Жизненный цикл

| Действие | Когда доступно | Результат |
|---|---|---|
| Активировать | Черновик: выбраны темы, типы вопросов, адресаты; дедлайн в будущем | Студенты видят задание и могут работать |
| Закрыть | Активно | Новые тесты и доработки студентов невозможны |
| Открыть заново | Закрыто | Снова активно |
| Продлить срок | Активно | Личный срок для одного студента — позже общего дедлайна |
| Сводка по тестам | Всегда | По каждому адресату: сколько тестов и в каком состоянии |

**Правила.** Дедлайн активного задания должен быть в будущем. Закрытое задание не редактируется.
