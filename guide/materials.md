# Материалы

Раздел объединяет **медиатеку** (изображения и видео) и **справочники базы знаний**: авторы, произведения, собрания и музеи, направления и стили, периоды, техники и материалы, термины. Справочники позволяют выбирать объекты из списка вместо ввода текста и ссылаться на них из текстов вопросов, тестов и заданий.

## Медиатека

Файлы, которые используются в вопросах: стимул вопроса, изображения в вариантах ответа.

**Загрузка** — кнопка «Загрузить»: изображения JPEG, PNG, WebP, TIFF до 50 МБ или видео MP4, WebM. Формат проверяется по содержимому файла, а не по расширению. Метаданные съемки (в том числе геолокация) из изображений удаляются. Если такой файл уже загружался, система предупредит о дубликате.

### Поля медиа

| Группа | Поле | Обязательно | Описание |
|---|---|---|---|
| Описание | Название | да | Для поиска в медиатеке: «Куинджи. Лунная ночь на Днепре». |
| | Альтернативный текст | для отправки вопроса | Что изображено — для незрячих пользователей. Без него вопрос с изображением не отправить на экспертизу. |
| | Подпись | нет | Подпись под изображением; можно ссылаться на объекты (`@slug`). |
| | Расшифровка (видео) | нет | Текст речи и описание происходящего. |
| Произведение | Изображено произведение | нет | Отметьте, если на изображении произведение искусства. |
| | Произведение (справочник) | нет | Выбор из справочника «Произведения». Поля ниже заполнятся из него автоматически. |
| | Автор произведения, Название произведения, Датировка, Техника, Собрание, Инв. номер | автор и название — если изображено произведение | Атрибуция. При выбранном произведении берутся из справочника. |
| Источник | Источник (URL) / Источник (описание) | одно из двух — для подтверждения прав | Откуда взят файл. |
| Права | Лицензия | да | Общественное достояние, CC0, CC BY, CC BY-SA, CC BY-NC, CC BY-NC-SA, По лицензии/договору, Учебное использование (норма закона), Не указана. |
| | Правообладатель, Атрибуция (credit line) | для подтверждения прав, кроме общественного достояния и CC0 | Кому принадлежат права и какую строку показывать рядом с изображением. |
| | Права | — | Не проверено, Права подтверждены, Ограничено. Меняется действием «Права». |
| | Основание прав | при решении о правах | На каком основании принято решение. |
| Классификация | Теги | нет | Ключевые слова через запятую. |
| Служебные | Файл, Загрузил, Где используется | — | Размер и формат, автор загрузки, список вопросов и тестов с этим медиа. |

### Права на изображения

- После загрузки права — «Не проверено». Подтвердить («Права подтверждены») может только преподаватель или администратор.
- Вопрос с изображением можно отправить на экспертизу и утвердить, только если права на все его медиа подтверждены.
- Если студент меняет поля прав у уже подтвержденного медиа, статус возвращается в «Не проверено».
- «Ограничено» показывает затронутые утвержденные и опубликованные тесты; сами тесты не меняются, решение об отзыве публикации принимает администратор.
- Используемое медиа нельзя удалить или заменить файл — только архивировать. Архивное медиа нельзя выбрать в новом вопросе.

## Справочники базы знаний

Ведут преподаватели и администраторы; студенты и эксперты читают и используют их в ссылках.

### Общие поля всех справочников

| Поле | Обязательно | Описание |
|---|---|---|
| Название | да | Как объект называется в интерфейсе и в ссылках по умолчанию. Без символов `[ ] < >`. |
| Slug (ключ ссылки) | нет | Ключ для ссылок `@slug`: буквы (латиница или кириллица), цифры, `-`, `_`. Пусто — сформируется из названия. Уникален в пределах справочника. **Нельзя изменить, если на объект уже ссылаются.** |
| Ссылка в тексте | — | Готовая запись для вставки в текст: `@person:kuindzhi`. |
| Варианты написания | нет | Другие написания и транслитерация через запятую — по ним работает поиск. |
| Описание | нет | Коротко, до 5000 символов; можно ссылаться на другие объекты. |
| Ссылок, Где используется | — | Сколько и какие вопросы, тесты, задания, медиа и объекты ссылаются на запись. |
| Статус | — | Активен / В архиве. |

### Поля по справочникам

| Справочник | Ссылка | Дополнительные поля | Связи |
|---|---|---|---|
| **Авторы** | `@person:…` | Год (от/до) — годы жизни; Годы жизни: рождение / смерть (текстом, «ок. 1520»); Страна | Направления |
| **Произведения** | `@artwork:…` | Год (от/до); Вид произведения (живопись, графика, скульптура, архитектура, ДПИ, фотография, другое); Датировка; Размеры; Инв. номер; Местонахождение (для архитектуры) | Авторы, Собрание (одно), Техники, Направления, Периоды |
| **Собрания и музеи** | `@collection:…` | Город; Страна; Сайт; Шаблон строки атрибуции | — |
| **Направления и стили** | `@movement:…` | Год (от/до) | Входит в (более общее направление), Периоды |
| **Периоды** | `@period:…` | Год (от/до) | Входит в (более крупная эпоха) |
| **Техники и материалы** | `@technique:…` | — | — |
| **Термины** | `@term:…` | Словоформы — подсказка для ссылок со склонением | См. также (другие термины) |

### Правила справочников

- Связь можно установить только с объектом нужного справочника (у произведения в поле «Авторы» — только авторы) и не с самим собой.
- Архивный объект нельзя выбрать в новых связях и новых ссылках; уже существующие сохраняются.
- Объект, на который ссылаются (текст, связь, медиа), удалить нельзя — только архивировать.
- Все изменения записываются в журнал.

## Ссылки на объекты в тексте

Где работают: формулировка, варианты и пояснение вопроса; описание и инструкции теста; инструкции задания; подпись медиа; описание объекта справочника. Не работают в альтернативном тексте, расшифровке видео, названиях и кодах.

| Вы пишете | После сохранения | Как видно в предпросмотре |
|---|---|---|
| `@kuindzhi` | `[Архип Куинджи](@person:kuindzhi)` | «Архип Куинджи», подчеркнуто пунктиром |
| `[Куинджи](@kuindzhi)` | `[Куинджи](@person:kuindzhi)` | «Куинджи» |
| `@term:sfumato` | `[Сфумато](@term:sfumato)` | «Сфумато» |
| `\@` или `user@mail.ru` | без изменений | символ @ |

- Ключ с `@` распознается в начале слова; `\@` — обычный символ.
- Если ключ есть в нескольких справочниках, система попросит указать вид: `@term:…` или `@movement:…`.
- Текст ссылки фиксируется при сохранении: последующее переименование объекта не меняет уже сохраненные и утвержденные тексты.
- Студент при прохождении теста видит только текст ссылки, без карточки объекта.
