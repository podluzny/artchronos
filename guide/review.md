# Экспертиза

Экспертиза — проверка версии вопроса или теста перед утверждением. Создается автоматически при отправке на экспертизу.

## Экспертизы

| Поле | Описание |
|---|---|
| Объект, Тип объекта | Что проверяется: тест или вопрос, с версией. |
| Состояние версии | Состояние проверяемой версии. |
| Статус экспертизы | Ожидает начала, Идет экспертиза, Возвращено на доработку, Принято, Отменено. |
| Очередь | Фильтр: «Мои экспертизы», «Не назначено». |
| Автор, Задание, Курс | Контекст работы. |
| Эксперт, Назначения | Основной эксперт и консультанты. |
| Итоговый комментарий | Обязателен при возврате на доработку без открытых замечаний. |
| Отправлено, Решение | Даты отправки и решения. |

## Назначение эксперта (действие «Назначить эксперта»)

| Поле | Описание |
|---|---|
| Эксперт | Активный пользователь с правом экспертизы; не автор проверяемого контента. |
| Роль | **Основной эксперт** принимает решение; **консультант** только комментирует. Основной эксперт один. |
| Причина | Обязательна при замене основного эксперта. |

## Рабочее место эксперта («Открыть экспертизу»)

- **Содержимое**: вопросы теста в предпросмотре, с правильными ответами.
- **Замечания** к тесту или конкретному вопросу. Важность: **блокирующее** (не дает принять), **существенное**, **незначительное**; или просто комментарий. Автор отмечает исправление, эксперт закрывает замечание. Открытые замечания переносятся в экспертизу следующей версии.
- **Checklist** — пункты шаблона; обязательные пункты нужно отметить перед принятием.
- **Решения**: «Принять» — версия утверждается; «Вернуть на доработку» — автор создает новую версию.

Закрытая экспертиза (принята или возвращена) больше не меняется.

## Шаблоны checklist

Список пунктов проверки для тестов и для вопросов. Ведет администратор.

| Поле | Описание |
|---|---|
| Название | Название шаблона. |
| Применяется к | Тест или вопрос. |
| Версия | Номер версии шаблона. |
| Пункты | Одна строка — один пункт: `КОД | текст | да/нет (обязательный)`. |

Действие «Изменить пункты» создает новую версию шаблона; она применяется к новым экспертизам, уже начатые сохраняют прежний набор.
