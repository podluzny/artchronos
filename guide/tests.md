# Тесты

Тест собирается из вопросов банка и (для преподавателя) правил случайного отбора. Студент создает тест в рамках активного задания, преподаватель — по заданию или по своему курсу. Тест хранится по версиям; публикует утвержденную версию администратор.

## Создание теста

| Поле | Обязательно | Описание |
|---|---|---|
| Задание или курс | да | Студент — только назначенное активное задание. |
| Название | да | Название теста. |
| Описание | нет | Кратко, о чем тест; можно ссылаться на объекты базы знаний. |

## Конструктор (действие «Конструктор»)

### Настройки версии

| Поле | Описание |
|---|---|
| Название | Название версии теста. |
| Лимит времени, мин | Пусто — без ограничения. |
| Попыток | Пусто — без ограничения числа попыток. |
| Проходной балл | Не больше максимального балла теста. |
| Навигация | Свободная или Линейная (без возврата к предыдущим вопросам). |
| Показ правильных ответов | После завершения попытки, После закрытия тестирования, Не показывать. |
| Перемешивание | Разделов, вопросов, вариантов ответа — для каждой попытки отдельно. |

### Структура

| Элемент | Описание |
|---|---|
| Раздел | Название, инструкции, свой лимит времени, перемешивание вопросов раздела. |
| Вопрос в разделе | Конкретная версия вопроса и баллы за него. Студент добавляет свои вопросы задания. |
| Правило случайного отбора | Только преподаватель: темы (с подтемами), диапазон сложности, число вопросов, баллы за вопрос. Вопросы выбираются из утвержденных вопросов курса; при утверждении теста пул фиксируется. |

## Поля в списке и карточке

Название, Состояние версии, Версия, Автор, Задание, Курс, Вопросов, Макс. балл, Структура, Готовность (что мешает отправке), Версии, Хэш содержимого, Статус, Изменен.

## Действия

| Действие | Кто | Описание |
|---|---|---|
| Предпросмотр | все с доступом | Как тест увидит студент |
| Отправить на экспертизу | автор | Проверяется готовность: число вопросов в пределах задания, готовность каждого вопроса. Черновики вопросов отправляются вместе с тестом. |
| Отозвать отправку | автор | Пока экспертиза не начата |
| Новая версия | автор | После возврата на доработку или из утвержденной версии |
| Опубликовать | администратор | Утвержденная версия становится доступной для прохождения |
| Отозвать публикацию | администратор | С обязательной причиной; новые попытки невозможны, результаты сохраняются |
| Публикации, Журнал | все с доступом | История публикаций и событий теста |
| В архив / Восстановить | автор, администратор | Опубликованный тест сначала нужно отозвать |
