# Глоссарий

| Термин | Значение |
|---|---|
| Архив | Состояние объекта, выведенного из оборота: скрыт из списков и выбора, но сохранен вместе со ссылками. |
| Версия | Зафиксированное состояние содержимого вопроса или теста. |
| Вопрос | Единица банка: формулировка, варианты, правильный ответ, метаданные. |
| Задание | Поручение студентам подготовить вопросы и тесты по темам курса. |
| Замечание | Комментарий эксперта к тесту или вопросу; может быть блокирующим. |
| Конструктор | Экран сборки теста: настройки, разделы, вопросы, правила отбора. |
| Медиа | Изображение или видео в медиатеке. |
| Правило отбора | Условие, по которому вопросы теста выбираются случайно из утвержденных вопросов курса. |
| Публикация | Перевод утвержденной версии теста в состояние «Опубликовано». |
| Слаг (slug) | Ключ объекта справочника для ссылок `@slug`. |
| Ссылка на объект | Запись `@slug` или `[текст](@slug)` в тексте, указывающая на объект базы знаний. |
| Справочник | Перечень объектов базы знаний одного вида (авторы, произведения и т. д.). |
| Тема | Узел тематического классификатора курса. |
| Тест | Набор вопросов с настройками прохождения. |
| Учебная цель | Формулировка того, что должен уметь студент по теме. |
| Хэш содержимого | Контрольная сумма замороженной версии; подтверждает, что содержимое не менялось. |
| Черновик | Редактируемая версия вопроса или теста. |
| Экспертиза | Проверка версии вопроса или теста экспертом с решением «принять» или «вернуть на доработку». |
| Alt text | Альтернативный текст изображения для незрячих пользователей. |
| Checklist | Список пунктов проверки, которые эксперт отмечает при экспертизе. |
