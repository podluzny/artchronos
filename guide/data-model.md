# Структура данных

Схема основных объектов и связей между ними. Стрелка `A → B` означает «A ссылается на B».

```
Предмет ─┐
         └─< Курс ──< Тема ──< Подтема
               │       └──< Учебная цель
               ├──< Группа студентов ──< Студенты
               ├── Преподаватели курса
               └──< Задание ──→ темы, цели, разрешенные типы вопросов,
                        │        адресаты (группы и студенты), эксперт по умолчанию
                        ├──< Вопрос (автор — студент) ──< Версии вопроса
                        └──< Тест   (автор — студент) ──< Версии теста ──< Разделы ──< Вопросы / правила отбора

Тип вопроса ──< Версии типа ←── Версия вопроса
Медиа ←── Версия вопроса (стимул, изображения в вариантах)
Медиа ──→ Произведение (справочник)

Справочники «Материалов»:
  Произведение ──→ Авторы, Собрание, Техники, Направления, Периоды
  Автор ──→ Направления        Направление ──→ Родитель, Периоды
  Период ──→ Родитель          Термин ──→ См. также
  Тексты вопросов, тестов, заданий, медиа, справочников ──@ссылки──→ любой объект справочника

Версия вопроса / теста ──< Экспертиза ──< Назначения экспертов, Замечания, Ответы checklist
Шаблон checklist ──< Экспертизы
Любое действие ──→ Запись журнала аудита
```

## Версии и неизменяемость

Вопросы и тесты хранят историю версий. Пока версия — черновик, ее можно править. После отправки на экспертизу версия «замораживается»: изменить ее нельзя, можно только создать новую версию на ее основе. У замороженной версии вычисляется **хэш содержимого** — контрольная сумма, по которой видно, что содержимое не менялось. Подробно — [Состояния и версии](/lifecycle.md).
