# Интерфейс и общие правила

## Вход и выход

- Вход — по email и паролю на странице `/admin/login`. После нескольких неудачных попыток вход временно блокируется.
- Сессия завершается после периода бездействия и в любом случае через ограниченное время после входа.
- Сменить пароль: ссылка на главной странице панели или прямой адрес `/account/password`.
- Новый пользователь получает либо ссылку активации (задает пароль сам), либо временный пароль, который нужно сменить при первом входе.

## Устройство панели

| Область | Что там |
|---|---|
| Левое меню | Группы разделов: Учебная структура, Задания, Материалы, Банк вопросов, Тесты, Экспертиза, Администрирование. Видны только разделы, доступные вашим ролям. |
| Верхнее меню | Ссылка «Справочник», имя пользователя и выход |
| Главная страница | Кто вошел, ссылки на справочник, документацию и смену пароля |
| Страница раздела | Список записей с поиском и фильтрами, кнопка «Создать» |
| Карточка записи | Поля записи и кнопки действий (редактировать, в архив, отправить на экспертизу и др.) |

## Списки, поиск и фильтры

- Поиск в верхней части списка ищет по названию (у вопросов — по формулировке).
- Кнопка «Фильтр» открывает панель фильтров. По умолчанию большинство списков показывают только активные записи; архивные — фильтр «Статус: В архиве».
- Сортировка — щелчок по заголовку колонки (где она поддерживается).
- Списки показывают только записи, которые вам разрешено видеть: например, преподаватель видит курсы, где он преподает, студент — свои вопросы и тесты.

## Подсказки к полям

Значок **(?)** рядом с названием поля показывает короткую подсказку: что вводить и на что поле влияет.

## Общие поля и правила

| Поле | Где встречается | Значение |
|---|---|---|
| ID | Все объекты | Внутренний идентификатор. В формах не вводится. |
| Статус (Активен / В архиве) | Предметы, курсы, темы, цели, группы, медиа, справочники, вопросы, тесты | Архивный объект скрыт из рабочих списков и не выбирается в новом контенте, но все данные и ссылки сохраняются. |
| Причина архивации | Архивируемые объекты | Обязательна при переносе в архив; попадает в журнал. |
| Версия, Состояние версии | Вопросы, тесты, типы вопросов | См. [Состояния и версии](/lifecycle.md). |

**Удаление и архив.** Объект, который где-то используется (курс с темами, медиа в вопросе, автор в справочнике), удалить нельзя — только перенести в архив. Восстановление возвращает его в рабочие списки.

**Одновременная правка.** Если запись изменил кто-то другой, пока вы ее редактировали, сохранение будет отклонено с просьбой обновить страницу. Так изменения коллег не теряются.

**Журнал.** Все значимые действия (создание, изменение, смена статуса, решения экспертизы, публикация) записываются в журнал аудита.

## Ссылки на базу знаний в тексте

В формулировках и пояснениях вопросов, описаниях тестов, инструкциях заданий, подписях медиа и описаниях объектов справочников можно ссылаться на объекты раздела [Материалы](/materials.md):

| Запись | Результат |
|---|---|
| `@kuindzhi` | ссылка с названием объекта: «Архип Куинджи» |
| `[Куинджи](@kuindzhi)` | ссылка со своим текстом — для склонения: «картины [Куинджи](@kuindzhi)» |
| `@person:kuindzhi` | явное указание справочника, если ключ есть в нескольких |
| `\@` | обычный символ @ |

После сохранения ссылка приводится к полному виду `[текст](@вид:ключ)`. Неизвестный ключ — ошибка у поля. Подробнее — в разделе [Материалы](/materials.md#ссылки-на-объекты-в-тексте).
