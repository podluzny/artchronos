# Справочник ArtChronos

ArtChronos — административная система, в которой готовят, проверяют и публикуют тесты по истории искусства. Справочник описывает разделы панели, объекты (сущности), из которых состоят данные, и поля этих объектов.

## Для кого

| Роль | Что делает в системе | С чего начать |
|---|---|---|
| Студент | Создает вопросы и тесты по заданиям преподавателя, дорабатывает их по замечаниям | [Задания](/assignments.md), [Банк вопросов](/item-bank.md), [Тесты](/tests.md) |
| Преподаватель | Ведет курсы, темы, группы, задания, справочники; проверяет работы студентов | [Учебная структура](/education.md), [Задания](/assignments.md), [Экспертиза](/review.md) |
| Эксперт | Проверяет назначенные ему вопросы и тесты | [Экспертиза](/review.md) |
| Администратор | Управляет пользователями и ролями, публикует тесты, смотрит журнал | раздел «Администрирование» |

Какие разделы видны конкретному пользователю, зависит от его ролей: см. [Роли и доступ](/roles.md).

## Как устроен справочник

- **Начало работы** — общие правила интерфейса, роли, схема данных и жизненный цикл версий.
- **Разделы меню** — по одной странице на группу левого меню панели. Для каждого объекта: назначение, поля, действия и правила.
- **Глоссарий** — термины системы.

В таблицах полей колонка «Обязательно» означает обязательность при сохранении формы. Подсказка к полю в самой панели открывается по значку **(?)** рядом с названием поля.

## Как открыть

- Из панели: ссылка **«Справочник»** в верхнем меню рядом с именем пользователя.
- По прямой ссылке: `/guide/`.

Раздел «Администрирование» справочника доступен только пользователям с ролью «Администратор» после входа в систему.
