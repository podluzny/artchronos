# Журнал аудита

> Раздел справочника для администраторов.

Журнал хранит неизменяемые записи о значимых действиях: вход и выход, создание и изменение объектов, смена статусов, решения экспертизы, публикация и отзыв, изменения прав. Записи нельзя изменить или удалить.

## Поля записи

| Поле | Описание |
|---|---|
| Время | Когда произошло действие. |
| Пользователь, Роли | Кто выполнил действие и какие роли у него были в тот момент. |
| Действие | Код события: `user.created`, `item.submitted`, `test.published`, `knowledge.updated` и т. п. |
| Тип объекта, ID объекта | Над чем выполнено действие. |
| Изменения | Какие поля изменились: было → стало. Пароли и токены не записываются. |
| Причина | Причина архивации, блокировки, отзыва и т. п. |
| ID запроса, IP | Для расследования инцидентов. |

## Как пользоваться

- Фильтры: по действию, пользователю, типу и ID объекта, периоду.
- История конкретного объекта открывается действием «История» / «Журнал» на его карточке.
