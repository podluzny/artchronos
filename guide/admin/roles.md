# Роли и права

> Раздел справочника для администраторов.

Роль — именованный набор прав. Право (permission) задается ключом и **областью действия**: свои, назначенные, курса, все. Пользователь получает объединение прав всех своих ролей. Каталог прав встроен в систему: новые права не создаются, их можно только включать в роли.

## Поля роли

| Поле | Обязательно | Описание |
|---|---|---|
| Код | да | Латиница, без пробелов: `METHODIST`. После создания не меняется. |
| Название | да | Название роли в интерфейсе. |
| Описание | нет | Для чего роль и кому ее назначать. |
| Системная | — | Системные роли (Студент, Преподаватель, Эксперт, Администратор) нельзя удалить. |
| Пользователей | — | Сколько пользователей имеют роль. |
| Права | — | Набор прав с областями; меняется действием «Права роли». |

## Правила

- Роль, назначенную пользователям, удалить нельзя.
- Изменение состава прав журналируется и действует со следующего запроса пользователей.
- Нельзя менять состав роли, которая назначена вам самим. Поэтому состав роли «Администратор» через интерфейс не меняется.
