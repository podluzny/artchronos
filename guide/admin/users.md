# Пользователи

> Раздел справочника для администраторов.

## Поля пользователя

| Поле | Обязательно | Описание |
|---|---|---|
| Email | да | Рабочий адрес — логин. Уникален. Изменение журналируется. |
| Имя | да | Как имя показано в списках, экспертизах и журнале. |
| Роли | да | Студент, Преподаватель, Эксперт, Администратор и пользовательские роли. Можно несколько. |
| Начальный режим | при создании | **Приглашение** — пользователь сам задаст пароль по одноразовой ссылке; **Временный пароль** — сменить при первом входе. |
| Временный пароль | для режима «Временный пароль» | Должен соответствовать политике паролей. |
| Статус | — | Приглашен, Активен, Заблокирован, В архиве. |
| Требуется смена пароля | — | Пользователь должен сменить пароль при следующем входе. |
| Причина статуса | — | Причина блокировки или архивации. |
| Последний вход, Создан, Изменен | — | Служебные даты. |

## Действия

| Действие | Описание |
|---|---|
| Создать | Новый пользователь; при режиме «Приглашение» показывается одноразовая ссылка — передайте ее пользователю, повторно она не показывается. |
| Роли | Изменить набор ролей. Свои роли изменить нельзя. Права вступают в силу при следующем запросе пользователя. |
| Заблокировать / Разблокировать | Блокировка с причиной: вход запрещен, сессии завершаются. Себя заблокировать нельзя. |
| В архив / Восстановить | Учетная запись скрывается и не может войти; данные и авторство сохраняются. |
| Сбросить пароль | Одноразовая ссылка или временный пароль. |
| Ссылка активации | Повторно выдать ссылку приглашенному пользователю. |
| История | События пользователя из журнала аудита. |

## Политика паролей

Не короче 12 символов; не совпадает с email; не из списка распространенных и не из одного повторяющегося символа. После серии неудачных попыток вход временно блокируется.

## Правила

- Нельзя изменить собственные роли, заблокировать или архивировать самого себя.
- Нельзя заблокировать, архивировать или лишить роли «Администратор» последнего активного администратора.
- Пользователи не удаляются — только архивируются; их авторство сохраняется.
