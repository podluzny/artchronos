# Состояния и версии

## Состояния версии вопроса и теста

| Состояние | Что значит | Что можно делать |
|---|---|---|
| Черновик | Версия редактируется автором | Править, отправить на экспертизу, удалить (если ни разу не отправлялась) |
| Отправлено на экспертизу | Ждет начала экспертизы | Автор может отозвать отправку, пока экспертиза не начата |
| На экспертизе | Эксперт работает с версией | Только чтение; автор отвечает на замечания |
| Возвращено на доработку | Эксперт вернул с замечаниями | Создать новую версию и исправить |
| Утверждено | Принято экспертом | Тест: публикация администратором. Вопрос: доступен в банке курса |
| Опубликовано | Тест доступен для прохождения | Отозвать публикацию (администратор) |
| В архиве | Версия выведена из оборота | Только чтение |

```
Черновик → Отправлено на экспертизу → На экспертизе → Утверждено → Опубликовано (тест)
    ↑              │ (отзыв отправки)        │
    └──────────────┘                        └→ Возвращено на доработку → новая версия (Черновик)
```

## Правила версий

- У вопроса и у теста одновременно может быть только **один черновик**.
- Новая версия создается из версии «Возвращено на доработку», «Утверждено» или «В архиве»; варианты ответов сохраняют свои ключи.
- Отправка теста на экспертизу отправляет и вошедшие в него черновики вопросов.
- Перед отправкой система проверяет готовность: тема у вопроса, правильный ответ, alt text и подтвержденные права у изображений, число вопросов в пределах задания.
- Опубликованную версию теста нельзя изменить; изменения — только через новую версию.

## Статусы экспертизы

| Статус | Значение |
|---|---|
| Ожидает начала | Экспертиза создана, эксперт назначен или ожидается |
| Идет экспертиза | Эксперт начал работу |
| Возвращено на доработку | Решение: нужны исправления |
| Принято | Решение: версия утверждена |
| Отменено | Отправка отозвана автором |

## Статусы задания

| Статус | Значение |
|---|---|
| Черновик | Задание настраивается, студенты его не видят |
| Активно | Студенты создают вопросы и тесты |
| Закрыто | Новые тесты и доработки студентов невозможны |
| В архиве | Скрыто из рабочих списков |

## Статусы пользователя

| Статус | Значение |
|---|---|
| Приглашен | Учетная запись создана, пароль еще не задан |
| Активен | Может входить в систему |
| Заблокирован | Вход запрещен, сессии завершены |
| В архиве | Учетная запись выведена из оборота; авторство сохранено |
