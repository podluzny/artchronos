# Учебная структура

Иерархия, к которой привязывается весь контент: **Предмет → Курс → Темы и подтемы → Учебные цели**, плюс **Группы студентов** курса.

## Предметы

Учебная дисциплина верхнего уровня, например «История искусства». Ведет администратор.

| Поле | Обязательно | Описание |
|---|---|---|
| Код | да | Короткий уникальный код: `HIST`. До 40 символов. |
| Название | да | Название предмета. |
| Курсов | — | Сколько курсов относится к предмету (вычисляется). |
| Статус, Причина архивации | — | См. [общие поля](/basics.md#общие-поля-и-правила). |

**Правила.** Архивный предмет нельзя выбрать для нового курса. Предмет с курсами удалить нельзя — только архивировать.

## Курсы

Конкретный курс предмета (поток, семестр). Создает администратор; он же назначает преподавателей.

| Поле | Обязательно | Описание |
|---|---|---|
| Предмет | да | К какому предмету относится курс. |
| Код | да | Уникален в пределах предмета: `RU19`. |
| Название | да | Как курс видят студенты и преподаватели. |
| Период | нет | Семестр или учебный год: «2026/27, осень». |
| Преподаватели | — | Назначаются действием «Назначить преподавателей». |

**Действия:** «Назначить преподавателей», «В архив», «Восстановить».
**Доступ.** Преподаватели курса ведут его темы, цели, группы и задания; студенты групп курса видят курс и его темы.

## Темы

Тематический классификатор курса; темы образуют дерево любой глубины (тема → подтема). Вопросы и медиа привязываются к темам.

| Поле | Обязательно | Описание |
|---|---|---|
| Курс | да | Курс, в котором используется тема. |
| Родительская тема | нет | Пусто — тема верхнего уровня; иначе — подтема. Тема не может быть потомком самой себя. |
| Название | да | Например, «Пейзаж XIX века». |
| Порядок | нет | Порядок среди тем одного уровня: меньше — выше. |
| Тема (путь) | — | Полный путь: «Пейзаж XIX века / Передвижники». |

**Правила.** Фильтр «по теме» в банке вопросов и в правилах отбора учитывает подтемы. Тему, используемую вопросами или заданиями, удалить нельзя.

## Учебные цели

Что студент должен уметь по теме. Используются для разметки вопросов и в заданиях.

| Поле | Обязательно | Описание |
|---|---|---|
| Тема | да | Тема, к которой относится цель (курс определяется темой). |
| Код | да | Короткий код: `LO-1`. |
| Формулировка | да | «Атрибутировать произведение по стилю». До 1000 символов. |
| Уровень (Блум) | нет | Помнить, Понимать, Применять, Анализировать, Оценивать, Создавать. |

## Группы студентов

Набор студентов курса. Задание можно адресовать группе целиком.

| Поле | Обязательно | Описание |
|---|---|---|
| Курс | да | Курс группы. |
| Название | да | «Г-1», «Поток А». |
| Студенты | — | Изменяются действием «Изменить состав». |
| Число студентов | — | Вычисляется. |

**Правила.** Студенты группы получают все задания, адресованные группе, в том числе добавленные в группу позже. Студент архивной группы перестает получать ее задания.
