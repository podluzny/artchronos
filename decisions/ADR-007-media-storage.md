# ADR-007: Media storage

| Поле | Значение |
|---|---|
| Статус | Proposed |
| Дата | 2026-10-08 |
| Задача | T-016 |
| Связанные требования | FR-MEDIA-001…007, NFR-SEC-006, NFR-PERF-004, NFR-EXT-004, NFR-DATA-006, BR-026 |

## Контекст
Медиа (изображения произведений, видео) — крупные бинарные файлы. Метаданные и права — доменные данные,
участвующие в правилах (BR-024…BR-026). Файлы должны быть доступны только авторизованным пользователям.

## Решение
1. **Разделение**: метаданные — `MediaAsset` в PostgreSQL; байты — в object storage через порт `MediaStorage`
   (`put`, `get`, `signedUrl`, `delete`, `exists`).
2. Драйверы: `S3Driver` (S3-compatible: AWS S3, MinIO, Yandex Object Storage и т.п.) — production; `LocalFsDriver` — dev/test.
   Выбор — конфигурацией (NFR-EXT-004).
3. Ключи объектов: `media/{assetId}/original.{ext}`, `media/{assetId}/{variant}.webp` — без пользовательских имен файлов.
4. Bucket приватный. Выдача — через авторизованный endpoint приложения, который проверяет `media.read` и
   возвращает redirect на короткоживущий signed URL (5 минут) или проксирует поток (LocalFs).
5. Файл неизменен: замена файла = новый `MediaAsset` (BR-026). Удаление байтов — только для медиа без значимого
   использования и после архивации + 30 дней (фоновая задача), с записью аудита.
6. Загрузка: проверка сигнатуры (file-type), лимиты, перекодирование изображений через `sharp` (удаление EXIF GPS),
   вычисление sha256; производные — асинхронно (очередь задач в PostgreSQL).
7. Бэкап object storage — версионирование bucket или репликация (NFR-DATA-006).

## Рассмотренные альтернативы
| Вариант | Почему отклонен |
|---|---|
| BLOB в PostgreSQL | Рост БД, бэкапы, производительность |
| `@adminjs/upload` как есть | Хранит путь в поле записи и не дает доменной модели прав и использования; может использоваться только как UI-компонент загрузки поверх нашего порта |
| Публичный bucket | Утечка неопубликованных материалов и материалов с ограниченными правами |

## Последствия
* Нужен воркер генерации производных (в том же процессе на MVP, отдельный — при росте).
* Signed URL требуют синхронизации времени и короткого TTL.

## Верификация
AT-MEDIA-001.*, AT-MEDIA-002.*; тест с двумя драйверами (NFR-EXT-004); тест доступа к файлу без права → 403/404.
